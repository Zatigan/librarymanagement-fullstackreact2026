# Library Management Fullstack

Application pédagogique full-stack composée de :

- `frontend/` : React + TypeScript + Vite
- `backend/` : Node.js / Express avec SQLite en mémoire

## Installation

À la racine :

```bash
npm install
npm run install:fullstack
```

## Démarrage

```bash
npm start
```

Le frontend est disponible sur http://localhost:4200 et l'API sur http://localhost:3000.

Cypress n'est volontairement pas installé : son ajout fait partie du brief E2E.
